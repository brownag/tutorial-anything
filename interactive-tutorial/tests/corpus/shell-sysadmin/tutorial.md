# Install a greeting command for your user

1. Scaffold: write `greet.conf.example` in this repo with `name=Ada`.
2. Config: copy it to `$HOME/.config/greet/greet.conf`.
3. Check config: confirm the file has `name=Ada`.
4. Install: create the executable `$HOME/.local/bin/greet`.
5. Run: `"$HOME/.local/bin/greet"` prints `hello, Ada`.
6. Verify: confirm both steps are in place.
