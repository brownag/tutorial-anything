# Greet CLI (v1 tutorial)

A tiny greeter. This tutorial was written for greet v1.

## 1. Read

The tutorial passes the name with `--name`. Note the flag.

## 2. Install greet

Create an executable `greet` script in the workspace that takes `--who`.

## 2b. Note your Python version

Record the output of `python3 --version` in your notes.

## 3. Run it

Run the greeter with the name Ada:

```sh
./greet --name Ada
```

It should print `Hello, Ada`.

## 4. Finish

Confirm the greeting printed as expected.
